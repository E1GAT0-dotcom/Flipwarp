FlipWarp Saver

Turns a project copied from FlipWarp in Web Lab into a real .sb3 file.

or press Ctrl+V on this page (⌘V on a Mac)

How to use it
  1. In FlipWarp (in Web Lab), choose File > Save to your computer… and press Copy the project.
  2. Come to this page and press Paste.
  3. The .sb3 file downloads. To post it on Scratch, go to scratch.mit.edu, make a new project, and use File > Load from your computer.

Everything happens in your browser: the project isn't sent anywhere.
