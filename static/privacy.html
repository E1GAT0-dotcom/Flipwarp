Flipwarp Privacy Policy

Updated September 2026

Flipwarp is a website made by E1GAT0_. It is a fork of TurboWarp, which is itself based on Scratch.

Flipwarp has no accounts, no sign-in, and no analytics. Nobody running it can tell who you are. This page lists every place your data goes anyway, because a site can still send information elsewhere without meaning anything by it.

The site itself

Flipwarp is a set of files with no server of its own behind them. It is published through GitHub Pages, so GitHub receives the ordinary information any web host receives when you open a page: your IP address, your browser, and which files you asked for. That is covered by GitHub's privacy statement, not by anything here.

What is kept in your browser

Your settings — the theme, the addon settings, Flipwarp's own settings, and a username for cloud variables — are stored in your own browser and are not sent anywhere. Clearing your browser's site data removes them. Nothing here is a cookie and nothing here follows you to other sites.

Opening a project from Scratch

When you open a project by its Scratch id, two other sites are involved. Scratch's own API does not allow other websites to ask it for a project directly, so the project id is sent to TurboWarp's trampoline service, which fetches it from Scratch on your behalf. Both the TurboWarp privacy policy and the Scratch privacy policy apply to that request.

Opening a project file from your own computer involves no other site at all. The file is read in your browser and never uploaded.

Cloud variables

Projects that use cloud variables connect to TurboWarp's cloud variable server, because Flipwarp does not run one. Your username and the project id may be logged there, and the values in cloud variables are sent to everyone else connected to the same project. See the TurboWarp privacy policy.

Extensions

The PenguinMod extensions in Flipwarp are stored with the site, so opening that tab does not contact PenguinMod. TurboWarp's extensions are fetched from extensions.turbowarp.org when you open their tab.

Some extensions have to talk to an outside service to do their job at all — translation and text-to-speech, for instance, use Scratch's and TurboWarp's APIs. An extension loaded from anywhere other than those galleries asks your permission before it contacts a website, but an extension you approve can do things Flipwarp cannot check.

What Flipwarp does not do

Flipwarp counts no views, runs no analytics, sets no advertising or tracking of any kind, and has no server that could store anything about you even if it wanted to.

Contact

Anything about privacy, or anything else, can go to E1GAT0_ on Scratch or to the issue tracker.
